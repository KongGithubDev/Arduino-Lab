# หลักสูตร: Arduino Sensors & Modules บน Lotus Nano Bot

สื่อการสอนชุดนี้ใช้ร่วมกับเอกสารเซนเซอร์/โมดูลใน [`sensors/`](../sensors) และ [`modules/`](../modules) โดยจัดเป็น 8 หน่วยการเรียนรู้ เรียงจากพื้นฐานไปสู่โปรเจกต์หุ่นยนต์

## คำอธิบายรายวิชา

ศึกษาโครงสร้างและการทำงานของบอร์ด Lotus Nano Bot (Arduino Nano) การเขียนโปรแกรมภาษา C/C++ บน Arduino IDE การรับสัญญาณดิจิทัลและแอนะล็อกจากเซนเซอร์ การควบคุมอุปกรณ์เอาต์พุต การใช้ไลบรารีและโปรโตคอลสื่อสาร (One-Wire, I2C, IR) การควบคุมมอเตอร์และเซอร์โว ฝึกออกแบบ ทดลอง บันทึกผล วิเคราะห์ และแก้ปัญหา เพื่อพัฒนาโปรเจกต์หุ่นยนต์และระบบอัตโนมัติอย่างง่าย โดยคำนึงถึงความปลอดภัยในการใช้อุปกรณ์ไฟฟ้า

## กลุ่มเป้าหมาย

- นักเรียนระดับมัธยมศึกษาตอนต้น - ตอนปลาย หรือผู้เริ่มต้นเรียน Arduino
- ไม่จำเป็นต้องมีพื้นฐานการเขียนโปรแกรมมาก่อน

## ผลการเรียนรู้ที่คาดหวัง

เมื่อเรียนจบหลักสูตร ผู้เรียนสามารถ

1. อธิบายหน้าที่ของพอร์ตและอุปกรณ์ในตัวของ Lotus Nano Bot และเลือกพอร์ตที่ไม่ชนกับอุปกรณ์บนบอร์ดได้
2. เขียนโปรแกรมรับค่าจากเซนเซอร์แบบ Digital และ Analog และแสดงผลผ่าน Serial Monitor / OLED ได้
3. ควบคุมอุปกรณ์เอาต์พุต (LED, Buzzer, Relay, Laser) ตามเงื่อนไขจากเซนเซอร์ได้
4. ติดตั้งและใช้งานไลบรารีสำหรับเซนเซอร์ที่ใช้โปรโตคอลเฉพาะได้
5. ควบคุมมอเตอร์ DC และเซอร์โวเพื่อสร้างพฤติกรรมหุ่นยนต์ (หลบสิ่งกีดขวาง, เดินตามเส้น) ได้
6. ออกแบบ สร้าง และนำเสนอโปรเจกต์ที่ผสานเซนเซอร์หลายชนิดได้

## ลำดับการใช้งานแนะนำ

1. ทำแบบทดสอบก่อนเรียน
2. เรียนหน่วย 1 ให้ทุกคนอัปโหลดโค้ดได้ก่อน
3. หน่วย 2-6 ให้แต่ละกลุ่มหมุนเวียนทดลองเซนเซอร์ (Station Rotation) ตามที่คู่มือครูแนะนำ
4. หน่วย 7-8 ทำงานเป็นทีมกับหุ่นยนต์
5. ทำแบบทดสอบหลังเรียนและนำเสนอโปรเจกต์
