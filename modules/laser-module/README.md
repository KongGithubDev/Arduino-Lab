# KY-008 --- Laser Transmitter Module

## รายละเอียด

Laser Module เป็นโมดูล Laser Diode ความแรงต่ำ (มักเป็น 5mW, 650nm สีแดง) ใช้สำหรับการชี้หรือทดสอบเซนเซอร์ต่างๆ ต้องใช้ความระมัดระวังในการใช้งาน

## คุณสมบัติ

- แรงดันไฟฟ้า: 5V DC
- ความยาวคลื่น: 650 nm (สีแดง)
- กำลัง: ~5 mW
- ควบคุมด้วย Digital (ON/OFF)

## ขาของโมดูล

| ขา (Module) | สีสาย | เชื่อมต่อกับ (Lotus Nano Bot) |
|-------------|-------|------------------------------|
| VCC (+)     | แดง   | 5V                           |
| GND (-)     | ดำ/น้ำตาล | GND                       |
| S (Signal)  | เหลือง | D3 หรือ A0 (D14)          |

## โค้ดตัวอย่าง

```cpp
// Laser Module Example for Lotus Nano Bot
// S -> D3

#define LASER_PIN 3

void setup() {
  Serial.begin(9600);
  pinMode(LASER_PIN, OUTPUT);
  digitalWrite(LASER_PIN, LOW);
  Serial.println("Laser Module Test Started");
}

void loop() {
  Serial.println("🔴 Laser ON");
  digitalWrite(LASER_PIN, HIGH);
  delay(2000);
  
  Serial.println("🔴 Laser OFF");
  digitalWrite(LASER_PIN, LOW);
  delay(2000);
}
```

## โค้ดตัวอย่างกระพริบ (Blinking)

```cpp
#define LASER_PIN 3

void setup() {
  pinMode(LASER_PIN, OUTPUT);
}

void loop() {
  // กระพริบเร็ว
  for (int i = 0; i < 10; i++) {
    digitalWrite(LASER_PIN, HIGH);
    delay(100);
    digitalWrite(LASER_PIN, LOW);
    delay(100);
  }
  
  delay(2000);
}
```

## หมายเหตุสำคัญ

- **⚠️ คำเตือน:** อย่าส่อง Laser เข้าตา! อาจทำให้ตาบอดได้
- ใช้ Laser 5mW หรือต่ำกว่าเท่านั้น
- ไม่ควรส่อง Laser ไปที่กล้องหรือเซนเซอร์รูปภาพ
- ใช้ได้กับการทดสอบ Avoidance Sensor, Photoresistor หรือ Line Tracking
- บน Lotus Nano Bot ใช้ D3 หรือ A0-A3 (เป็น Digital Output) ได้
- หากต่อที่ D3 บัซเซอร์ในตัวอาจมีเสียงคลิกตอนเปิด/ปิด ถ้าไม่ต้องการให้ย้ายไป A0 (`#define LASER_PIN 14`)

## กิจกรรมการเรียนรู้

### จุดประสงค์การเรียนรู้
1. นักเรียนต่อ Laser Module และควบคุมการเปิด/ปิดด้วย `digitalWrite()` ได้อย่างปลอดภัย
2. นักเรียนวัดและบันทึกขนาดจุดแสงเลเซอร์ที่ระยะต่าง ๆ ได้
3. นักเรียนประยุกต์ใช้เลเซอร์คู่กับเซนเซอร์แสงเพื่อทำ "ประตูลำแสง" ได้

### ขั้นตอนการทดลอง
1. ตกลงกฎความปลอดภัยก่อน: หันเลเซอร์ไปที่ผนัง/กระดาษเท่านั้น ห้ามส่องตาหรือกระจก
2. ต่อสาย VCC→5V, GND→GND, S→D3 แล้วอัปโหลดโค้ดตัวอย่างแรก
3. วัดเส้นผ่านศูนย์กลางจุดแสงบนกระดาษที่ระยะ 0.5 m, 1 m และ 2 m
4. อัปโหลดโค้ดกระพริบ แล้วปรับ `delay()` ให้กระพริบเร็วจนตามองไม่ทันว่าดับ บันทึกค่า delay

### ตารางบันทึกผล
| ครั้งที่ | สภาวะ/การกระทำ | ค่าที่อ่านได้ | ผลที่สังเกตได้ |
|---|---|---|---|
| 1 | ระยะ 0.5 m | ขนาดจุด = mm | |
| 2 | ระยะ 1 m | ขนาดจุด = mm | |
| 3 | ระยะ 2 m | ขนาดจุด = mm | |

### คำถามท้ายการทดลอง
1. แสงเลเซอร์ต่างจากแสง LED ทั่วไปอย่างไร
2. ทำไมจุดแสงจึงใหญ่ขึ้นเล็กน้อยเมื่อระยะไกลขึ้น
3. จะใช้เลเซอร์กับ Photoresistor ทำระบบนับคนเดินผ่านประตูได้อย่างไร

<details>
<summary>แนวคำตอบ (สำหรับครู)</summary>

1. เลเซอร์เป็นแสงสีเดียว (650 nm) มีทิศทางขนานและรวมพลังงานเป็นลำแคบ จึงอันตรายต่อดวงตามากกว่า LED
2. ลำแสงมีการบานออก (Divergence) เล็กน้อยจากเลนส์และขนาดช่องปล่อยแสง ระยะไกลขึ้นจุดจึงใหญ่ขึ้น
3. ส่องเลเซอร์ไปที่ Photoresistor ตลอดเวลา เมื่อมีคนตัดลำแสงค่าแสงจะลดลงทันที ให้โปรแกรมนับครั้งที่ค่าตกต่ำกว่าเกณฑ์

</details>

### ภารกิจท้าทาย
- ต่อเลเซอร์ที่ A0 แล้วใช้ Knob ในตัว (A7) ปรับความเร็วการกระพริบ (`delay(map(analogRead(A7), 0, 1023, 50, 1000))`) พร้อมกดปุ่ม OK (D2) เพื่อเปิด/ปิดระบบ
