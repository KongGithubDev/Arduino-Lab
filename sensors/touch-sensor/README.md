# KY-036 --- Touch Sensor

## รายละเอียด

Touch Sensor โมดูล TTP223 เป็นเซนเซอร์สัมผัสแบบ Capacitive ตรวจจับการสัมผัสของนิ้วมือ ไม่ต้องใช้แรงกด มีวงจร IC TTP223 ในตัว

## คุณสมบัติ

- แรงดันไฟฟ้า: 2.5V - 5.5V DC
- เอาต์พุต: Digital (Active High หรือ Low ปรับได้)
- กระแสทำงานต่ำ (~1.5 µA)
- ตรวจจับระยะห่าง ~5 mm

## ขาของโมดูล

| ขา (Module) | สีสาย | เชื่อมต่อกับ (Lotus Nano Bot) |
|-------------|-------|------------------------------|
| VCC         | แดง   | 5V                           |
| GND         | ดำ/น้ำตาล | GND                       |
| I/O (Signal)| เหลือง | D3 หรือ A0 (D14)          |

> **หมายเหตุ:** ในชุดเซนเซอร์ 37 in 1 บางชุด KY-036 เป็นโมดูล Metal Touch (มี DO, AO และ Potentiometer) ให้ต่อ DO แทนขา I/O และตรวจสอบระดับลอจิก HIGH/LOW ด้วย Serial Monitor

## โค้ดตัวอย่าง

```cpp
// Touch Sensor Example for Lotus Nano Bot
// I/O -> D3

#define TOUCH_PIN 3
#define LED_PIN 13

void setup() {
  Serial.begin(9600);
  pinMode(TOUCH_PIN, INPUT);
  pinMode(LED_PIN, OUTPUT);
  Serial.println("Touch Sensor Test Started");
}

void loop() {
  int touched = digitalRead(TOUCH_PIN);
  
  if (touched == HIGH) {  // สัมผัสที่เซนเซอร์
    Serial.println("👆 Touch Detected!");
    digitalWrite(LED_PIN, HIGH);
  } else {
    digitalWrite(LED_PIN, LOW);
  }
  
  delay(100);
}
```

## โค้ดตัวอย่าง Toggle Switch (กดเปิด/ปิด)

```cpp
#define TOUCH_PIN 3
#define RELAY_PIN 13  // LED บนบอร์ด Nano (หากต่อรีเลย์ภายนอกให้ใช้ A0-A3 เพราะ D4-D12 ใช้กับมอเตอร์/เซอร์โว)

bool state = false;
int lastTouch = LOW;

void setup() {
  Serial.begin(9600);
  pinMode(TOUCH_PIN, INPUT);
  pinMode(RELAY_PIN, OUTPUT);
}

void loop() {
  int touch = digitalRead(TOUCH_PIN);
  
  if (touch == HIGH && lastTouch == LOW) {
    state = !state;
    digitalWrite(RELAY_PIN, state);
    Serial.println(state ? "🔵 ON" : "🔴 OFF");
    delay(300);  // Debounce
  }
  
  lastTouch = touch;
}
```

## หมายเหตุ

- ไม่ต้องกดแรง เพียงแค่สัมผัสเบาๆ หรือเข้าใกล้
- หากต้องการให้เป็น Toggle Mode (A หรือ B) ให้บัดกรีจัมเปอร์บนโมดูล
- บางรุ่นมีขา A และ B สำหรับเลือกโหมด Momentary หรือ Toggle
- บน Lotus Nano Bot ใช้ D3 หรือ A0-A3 (เป็น Digital) ได้
- D3 ต่อร่วมกับบัซเซอร์บนบอร์ด อาจได้ยินเสียงคลิกเบาๆ เมื่อสัญญาณเปลี่ยน หากไม่ต้องการให้ย้ายไป A0-A3 (D14-D17)

## กิจกรรมการเรียนรู้

### จุดประสงค์การเรียนรู้
1. นักเรียนสามารถอ่านสัญญาณจาก Touch Sensor แบบ Capacitive และควบคุม LED ได้
2. นักเรียนสามารถเขียนโปรแกรม Toggle โดยตรวจจับขอบสัญญาณ (LOW -> HIGH) ได้
3. นักเรียนสามารถทดสอบว่าวัสดุชนิดใดสามารถกระตุ้นเซนเซอร์ผ่านได้

### ขั้นตอนการทดลอง
1. ต่อ I/O -> D3 แล้วอัปโหลดโค้ดตัวอย่างแรก แตะเซนเซอร์และสังเกต LED D13
2. แตะผ่านกระดาษ 1 แผ่น, พลาสติกบาง และถุงมือผ้า บันทึกว่าตรวจจับได้หรือไม่
3. ลองแตะด้วยดินสอและช้อนโลหะ บันทึกผล
4. อัปโหลดโค้ด Toggle Switch แตะ 1 ครั้งเพื่อเปิด และอีก 1 ครั้งเพื่อปิด LED

### ตารางบันทึกผล
| ครั้งที่ | สภาวะ/การกระทำ | ค่าที่อ่านได้ | ผลที่สังเกตได้ |
|---|---|---|---|
| 1 | แตะด้วยนิ้วโดยตรง | | |
| 2 | แตะผ่านกระดาษ 1 แผ่น | | |
| 3 | แตะด้วยช้อนโลหะที่ถือในมือ | | |
| 4 | แตะ 2 ครั้ง (โค้ด Toggle) | | |

### คำถามท้ายการทดลอง
1. Touch Sensor แบบ Capacitive ตรวจจับนิ้วมือได้อย่างไร
2. วัสดุใดที่ตรวจจับผ่านได้และไม่ได้ เพราะเหตุใด
3. Touch Sensor สามารถใช้แทนปุ่มกดบนหุ่นยนต์ได้อย่างไร และมีข้อดีอะไร

1. ร่างกายมนุษย์นำไฟฟ้าและมีความจุไฟฟ้า เมื่อนิ้วเข้าใกล้แผ่นสัมผัส ความจุของแผ่นเพิ่มขึ้น IC จึงตรวจพบและเปลี่ยนเอาต์พุต
2. วัสดุบางที่เป็นฉนวน (กระดาษ พลาสติกบาง) มักตรวจผ่านได้เพราะสนามไฟฟ้าทะลุผ่าน วัสดุหนาหรือไม่ต่อกับร่างกาย เช่น ดินสอที่วางเฉยๆ ตรวจไม่ได้ โลหะที่ถือในมือตรวจได้เพราะนำไฟฟ้าต่อกับร่างกาย
3. ใช้เป็นปุ่มเริ่ม/หยุด ไม่มีชิ้นส่วนเคลื่อนที่จึงไม่สึกหรอ และซ่อนไว้ใต้ฝาพลาสติกบางได้

</details>

### ภารกิจท้าทาย
- ใช้ Touch Sensor เป็นสวิตช์สั่งหุ่นยนต์: แตะ 1 ครั้งให้มอเตอร์ทั้งสองข้างเริ่มหมุน แตะอีกครั้งให้หยุด พร้อมส่งเสียงสั้นจากบัซเซอร์ (ย้าย I/O ไป A0 เพื่อให้ D3 ว่างสำหรับบัซเซอร์)
