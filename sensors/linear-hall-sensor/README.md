# KY-024 --- Linear Hall Sensor

## รายละเอียด

Linear Hall Sensor เป็นเซนเซอร์แม่เหล็กแบบเชิงเส้น ให้ค่าแรงดันเอาต์พุตเปลี่ยนแปลงเชิงเส้นตามความเข้มของสนามแม่เหล็ก สามารถวัดทิศทางและความแรงของแม่เหล็กได้อย่างละเอียด

## คุณสมบัติ

- แรงดันไฟฟ้า: 3.3V - 5V DC
- เอาต์พุต: Digital (DO) และ Analog (AO)
- มี LED แสดงสถานะ
- มีตัวปรับค่า (Potentiometer)

## ขาของเซนเซอร์

| ขา (Sensor) | สีสาย | เชื่อมต่อกับ (Lotus Nano Bot) |
|-------------|-------|------------------------------|
| VCC         | แดง   | 5V                           |
| GND         | ดำ/น้ำตาล | GND                       |
| DO (Digital)| เหลือง | D3 หรือ A1 (D15)          |
| AO (Analog) | ขาว   | A0, A1, A2, A3 หรือ A6 (ห้ามใช้ขาเดียวกับ DO) |

## โค้ดตัวอย่าง

```cpp
// Linear Hall Sensor Example for Lotus Nano Bot
// AO -> A0, DO -> D3 (optional)

#define HALL_ANALOG_PIN A0
#define HALL_DIGITAL_PIN 3

void setup() {
  Serial.begin(9600);
  pinMode(HALL_DIGITAL_PIN, INPUT);
  Serial.println("Linear Hall Sensor Test Started");
}

void loop() {
  int analogValue = analogRead(HALL_ANALOG_PIN);
  float voltage = analogValue * (5.0 / 1023.0);
  int digitalValue = digitalRead(HALL_DIGITAL_PIN);
  
  Serial.print("Analog: ");
  Serial.print(analogValue);
  Serial.print(" (");
  Serial.print(voltage);
  Serial.print(" V) | Digital: ");
  Serial.println(digitalValue);
  
  // ค่าปกติประมาณ 2.5V (512)
  if (analogValue > 550) {
    Serial.println("🧲 South Pole / Strong Field (+)");
  } else if (analogValue < 470) {
    Serial.println("🧲 North Pole / Strong Field (-)");
  } else {
    Serial.println("❌ No Significant Field");
  }
  
  delay(200);
}
```

## หมายเหตุ

- ค่าปกติประมาณ 2.5V (512) เมื่อไม่มีแม่เหล็ก
- ค่าสูงขึ้นเมื่อแม่เหล็กขั้ว S เข้าใกล้
- ค่าต่ำลงเมื่อแม่เหล็กขั้ว N เข้าใกล้
- ใช้ได้กับการวัดระยะทางด้วยแม่เหล็ก, นับรอบมอเตอร์
- บน Lotus Nano Bot ใช้ A0-A3, A6 สำหรับอ่านค่าอนาลอก
- D3 ต่อร่วมกับบัซเซอร์บนบอร์ด อาจได้ยินเสียงคลิกเบาๆ เมื่อสัญญาณเปลี่ยน หากไม่ต้องการให้ย้ายไป A0-A3 (D14-D17)

## กิจกรรมการเรียนรู้

### จุดประสงค์การเรียนรู้
1. นักเรียนสามารถอ่านค่าอนาลอกจาก Linear Hall Sensor และแปลงเป็นแรงดัน (V) ได้
2. นักเรียนสามารถระบุขั้วแม่เหล็ก (N/S) จากการเพิ่มขึ้นหรือลดลงของค่าที่อ่านได้
3. นักเรียนสามารถอธิบายความสัมพันธ์ระหว่างระยะห่างของแม่เหล็กกับค่าที่อ่านได้

### ขั้นตอนการทดลอง
1. ต่อสาย AO -> A0 และ DO -> D3 ตามตาราง แล้วอัปโหลดโค้ดตัวอย่าง
2. เปิด Serial Monitor (9600) บันทึกค่า Analog ขณะไม่มีแม่เหล็กใกล้ (ค่าอ้างอิง ~512)
3. นำแม่เหล็กขั้วหนึ่งเข้าใกล้ที่ระยะ 5 cm, 2 cm และ 0.5 cm บันทึกค่าทุกระยะ
4. กลับด้านแม่เหล็กแล้วทำซ้ำ สังเกตว่าค่าเพิ่มขึ้นหรือลดลง
5. ปรับ Potentiometer แล้วสังเกตว่าค่า Digital และ LED บนโมดูลเปลี่ยนที่ระยะเท่าใด

### ตารางบันทึกผล
| ครั้งที่ | สภาวะ/การกระทำ | ค่าที่อ่านได้ | ผลที่สังเกตได้ |
|---|---|---|---|
| 1 | ไม่มีแม่เหล็ก | | |
| 2 | แม่เหล็กขั้ว S ห่าง 2 cm | | |
| 3 | แม่เหล็กขั้ว N ห่าง 2 cm | | |
| 4 | แม่เหล็กแนบชิดเซนเซอร์ (0.5 cm) | | |

### คำถามท้ายการทดลอง
1. Linear Hall Sensor ต่างจาก Hall Switch (เอาต์พุตแบบเปิด/ปิด) อย่างไร
2. เมื่อนำแม่เหล็กเข้าใกล้มากขึ้น ค่า Analog เปลี่ยนแปลงอย่างไร และขั้ว N กับ S ให้ผลต่างกันอย่างไร
3. จะนำเซนเซอร์นี้ไปวัดตำแหน่งหรือนับรอบล้อของหุ่นยนต์ได้อย่างไร

1. Linear Hall Sensor ให้แรงดันเปลี่ยนต่อเนื่องตามความเข้มสนามแม่เหล็ก จึงบอกได้ทั้งความแรงและขั้ว ส่วน Hall Switch บอกได้เพียงมี/ไม่มีแม่เหล็ก
2. ยิ่งใกล้ ค่ายิ่งห่างจาก ~512 มากขึ้น ขั้วหนึ่งทำให้ค่าสูงขึ้น (เข้าใกล้ 1023) อีกขั้วทำให้ค่าต่ำลง (เข้าใกล้ 0)
3. ติดแม่เหล็กที่ล้อ แล้วนับจำนวนครั้งที่ค่าเกิน Threshold ต่อหนึ่งรอบ หรือใช้ขนาดของค่าประมาณระยะห่างของแม่เหล็ก

- แสดงค่า Analog และขั้วแม่เหล็ก (N/S) บนจอ OLED ของ Lotus Nano Bot พร้อมแถบกราฟแท่งที่ยาวตามความแรงของสนามแม่เหล็ก
