# Lotus Nano Bot Simulator (3D)

เว็บจำลองบอร์ด **Lotus Nano Bot** + ชุดเซนเซอร์ **37-in-1** แบบ 3 มิติ ต่อสายและรันโค้ด Arduino ได้ในเบราว์เซอร์

## เปิดใช้งาน

**ออนไลน์:** https://arduino-lab-wheat.vercel.app (ใช้ได้บนคอมพิวเตอร์, iPad และมือถือ)

เว็บต้องเปิดผ่านเว็บเซิร์ฟเวอร์ (เปิดไฟล์ตรงๆ แบบ `file://` จะโหลดโมเดล 3D ไม่ได้)

```bash
# จากโฟลเดอร์หลักของโปรเจกต์
python -m http.server 8000
# แล้วเปิด http://localhost:8000/simulator/
```


## วิธีใช้

1. เลือกโมดูลจาก **คลังโมดูล** ด้านซ้าย โมดูลจะถูกวางบนโต๊ะ **ต่อสายให้อัตโนมัติ** ตามตารางในเอกสาร และ **โหลดโค้ดตัวอย่าง** ของโมดูลนั้นให้ทันที
   - วางได้หลายโมดูลพร้อมกัน ถ้าพอร์ตที่เอกสารกำหนด (เช่น A0) มีโมดูลอื่นใช้อยู่แล้ว ระบบจะเลือกพอร์ตว่างถัดไป (A1, A2, …) และปรับเลขขาในโค้ดตัวอย่างให้ตรงอัตโนมัติ
2. **ต่อสายเองได้อิสระ:** คลิกขาโมดูล แล้วคลิกช่องบนหัวต่อ
   - ช่องขาว = สัญญาณ (S)
   - ช่องแดง = 5V
   - ช่องดำ = GND

   ต่อได้หลายเส้นต่อขา/ช่อง (สายจะซ้อนกันแบบ Dupont ต่อพ่วง) **คลิกที่หัวสายสีดำ** เพื่อถอดปลายนั้นแล้วคลิกตำแหน่งใหม่เพื่อเสียบ (กด Esc เพื่อทิ้งสาย) คลิกขวาที่สายเพื่อลบ
3. **จ่ายไฟให้บอร์ด** (แถบด้านบน หรือคลิกบนบอร์ด 3D)
   - **USB**: จ่ายไฟ 5V ให้บอร์ดและเซนเซอร์ (เปิดไว้เป็นค่าเริ่มต้น)
   - **แบต** (LiPo 7.4V ที่ขั้ว T-Plug) + **สวิตช์ ON/OFF**: จำเป็นสำหรับมอเตอร์ ML/MR
   - ถ้าไม่มีไฟเลย บอร์ดและโมดูลจะหยุดทำงาน และเมื่อจ่ายไฟใหม่ โปรแกรมที่อัปโหลดไว้จะเริ่มรันใหม่เหมือนบอร์ดจริง
4. **ใช้ได้ทุกช่องบนบอร์ด**: A0-A6, D0, D1, D3, SV1-SV3 (เสียบ **เซอร์โว SG90** ได้), ML/MR (เสียบ **มอเตอร์ TT + ล้อ** ได้), AA0-AA3 (อ่านผ่าน ADS1115)
5. กด **รัน** (ปุ่มเดียวกันกลายเป็น **หยุด** ขณะทำงาน) แก้โค้ดได้ตามต้องการ หรือเลือกตัวอย่างอื่นแล้วกด **โหลดโค้ด**
6. ปรับ **สภาพแวดล้อมจำลอง** ได้ เช่น ความสว่าง อุณหภูมิ แม่เหล็ก เสียง การกดปุ่ม และรีโมท IR แล้วดูผลใน Serial Monitor หรือ Serial Plotter
7. อุปกรณ์บนบอร์ดใช้ได้จริง:
   - ปุ่มฟ้า D2 (คลิกค้าง)
   - Knob A7 (ลากซ้าย-ขวา)
   - จอ OLED
   - บัซเซอร์ D3
   - LED L (D13)
   - มอเตอร์ และเซอร์โว: ดูสถานะที่แถบล่าง

ระบบตรวจการต่อสายจะเตือนเมื่อ:
- ต่อกลับขั้ว
- เสียบขาสัญญาณผิดช่อง
- ใช้พอร์ตที่ชนกับอุปกรณ์บนบอร์ด (D3 บัซเซอร์, A4/A5 I2C, D0/D1 Serial)

## ภาษา Arduino ที่รองรับ

ตัวจำลองแปลงโค้ด Arduino (C++) เป็น JavaScript แล้วรันบน ATmega328P เสมือน ใช้ได้กับโค้ดเพื่อการเรียนรู้เกือบทั้งหมด

| ส่วนที่รองรับ | รายการ |
|-------------|--------|
| ไวยากรณ์ | ตัวแปร, ฟังก์ชัน, อาร์เรย์, `#define`, `if`/`for`/`while`/`switch`, `String` |
| ขาและเวลา | `pinMode`, `digitalRead/Write`, `analogRead/Write`, `tone`/`noTone`, `millis`/`delay`, `map`/`constrain`, `attachInterrupt` (D2/D3) |
| สื่อสาร | `Serial` (print/println/read) |
| ไลบรารี | `Servo`, `Adafruit_SSD1306` (ข้อความและรูปทรง), `DHT`, `OneWire` + `DallasTemperature`, `IRremote` 4.x |

ข้อจำกัด:
- ไม่รองรับ pointer, struct หรือ class ที่เขียนเอง
- ไม่รองรับ register ระดับต่ำ (`PORTB`, `PCINT`)
- จังหวะเวลาเป็นค่าประมาณ

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|-----|--------|
| `index.html`, `css/style.css` | หน้าเว็บ |
| `js/app.js` | ต่อสาย, วงจรไฟฟ้า, อุปกรณ์บนบอร์ด, เสียง, Serial |
| `js/scene.js` | ฉาก three.js (แสง, เงา, Bloom), สาย Jumper |
| `js/runtime.js` | ตัวแปลง Arduino → JS และ MCU เสมือน |
| `js/behaviors.js` | พฤติกรรมไฟฟ้าของโมดูลทั้ง 37 ตัว |
| `js/catalog.js` | ข้อมูลโมดูล + โค้ดตัวอย่าง (สร้างจาก README) |
| `models/*.glb` | โมเดล 3D ส่งออกจาก Blender |
